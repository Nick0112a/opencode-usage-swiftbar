# OpenCode Usage for SwiftBar · OpenCode 额度菜单栏 📊

把 OpenCode 的额度放进 macOS 菜单栏：5 小时 / 本周 / 本月三档用量一目了然，快用完时还会主动提醒 ⏰

## ✨ 功能

- 📊 **三档额度实时显示** —— 50 根细刻度的用量条，按紧张程度变色：🟢 绿 → 60% 🟠 琥珀 → 85% 🔴 红，精确百分比在右侧胶囊里
- 🔔 **快用完时提醒** —— 任一档越过 85% 发一条系统通知；每档每个周期只提醒一次，不会连环轰炸
- 🏃 **进度提示** —— 用得比时间流逝明显快时，该档标红并注明「进度偏快」
- ⚡ **Zen 按量付费自动识别** —— key 没有 Go 窗口时自动切换成 Zen 卡片
- 🔑 **多把 Key，可以起名** —— 「个人」「工作」随便叫，菜单里一点就切换
- 🌍 **七种语言** —— 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Español / Français，切换立即生效
- ☁️ **断网不掉数据** —— 读取失败时继续显示上一次的读数，并注明是多久前的

## 📦 环境要求

- 🍎 macOS + [SwiftBar](https://github.com/swiftbar/SwiftBar)
- 🐍 python3（可选 Pillow：没有时菜单栏图标会退化成文字，其余功能不受影响）

## 🚀 安装

```bash
git clone https://github.com/Nick0112a/opencode-usage-swiftbar.git
cd opencode-usage-swiftbar
./install.sh
```

## 🪄 第一次使用

1. 🖱️ 菜单栏出现图标后点开它
2. 📋 「API Key ▸ 添加 Key ▸ 从剪贴板导入…」——先在 OpenCode 后台复制好你的 key
3. ✅ 完成！之后每 5 分钟自动刷新一次

## 🖥️ 菜单里有什么

| 位置 | 说明 |
|---|---|
| 📊 三档用量 + 刻度条 | 百分比在右侧胶囊里；点任意一行可打开 OpenCode 控制台 |
| 🔑 API Key ▸ | 已存的所有 key（打勾 = 正在用）；可起名、新增、重命名、删除 |
| 🌍 语言 ▸ | 七种语言，即点即换 |
| 🎛️ 打开控制台 / 刷新 | 跳转 OpenCode 后台 / 立即刷新一次 |

## ❓ 常见问题

- **Zen 的余额怎么看不了？** OpenCode 没有公开余额接口，只能去网页控制台看 🌐
- **美元上限哪来的？** 官方文档的标准 Go 额度（$12 / $30 / $60）；接口本身只返回百分比，Go Plus 额度不同，所以标题里写的是 ≈
- **通知没弹出来？** 第一次触发时系统会请求通知权限，允许即可 🔔
- **刻度条右端留了一小段空？** 那是菜单自带的边距

## ⚠️ 已知限制

- 依赖 OpenCode 网页控制台使用的两个未公开接口，返回结构可能变化——变化时会显示缓存读数并明确报错，不会崩
- 美元上限是文档标注值，接口本身只返回百分比
- 仅支持 macOS

改这个插件之前，先读 [DEVELOPMENT.md](DEVELOPMENT.md)——里面是 SwiftBar 的几个反直觉行为，不读很容易踩回去。
